# pyrotha

The seed for a core design of peer-to-peer distributed interplanetary immutable Tha data model for emergent human interaction and coexistence.

It aims to be an application of the abstract ideal [eidotha](https://kjelloh.github.io/eidotha/)

The name is a word play on the greek word 'phyros' menaing 'fire' and 'Tha' which the the working name of the four meta tier data model eluded to in YouTube playlist ['C++ Tha Tha'](https://www.youtube.com/watch?v=zdF_evtjJGg&list=PLl2MXgNWEbwE34Cxjx9uW-wdq7RyZ_uQj).

Also see [cpptha](https://kjelloh.github.io/cpptha/) for an attempt to define a C++ meta language based on the 'Tha' type system data model idea.
